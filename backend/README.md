# contractapi

PyPI distribution for **contractapi** (import name unchanged).

```bash
pip install 'contractapi[redis]'
contractapi version
contractapi serve
```

Docs: see the [repository README](https://github.com/Iman-Sharei/contractapi) and `docs/` folder.

**Maturity:** Beta (`0.5.0b1`). See `docs/STABILITY.md`.
