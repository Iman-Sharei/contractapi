# dataapi-pg

PyPI distribution for **dataapi** (import name unchanged).

```bash
pip install 'dataapi-pg[redis]'
dataapi version
dataapi serve
```

Docs: see the [repository README](https://github.com/imansharei/dataapi) and `docs/` folder.

**Maturity:** Beta (`0.5.0b1`). See `docs/STABILITY.md`.
